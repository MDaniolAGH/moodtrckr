# moodtrckr — materiały prowadzącego

Materiały prowadzącego do kursu *Innowacyjne aplikacje mobilne w chirurgii i medycynie 4.0*
(Digital Health Engineering Studio). **Repozytorium prywatne** — zawiera klucze odpowiedzi,
ukryte fakty ról i pliki sabotażu; nie udostępniać studentom.

| Folder | Zawartość |
|--------|-----------|
| `pakiet-prowadzacego-W1/` | Wykład 1 (slajdy 12–23): scenariusz, prompty, role, karty do druku, demo Copilota |
| `skills/` | Skille Copilota: Business Analyst (`ba-*`), `verify-claim`, `test-first-fix`, `pr-review`, mHealth (`mh-*`, 4 poziomy: dane → OWASP → RODO/MDR → IEC 62304/ISO 14971) |
| `lancuch-agentow/` | 7 agentów Copilota z przekazaniem: odkrycie → issue → architektura → development → testy jednostkowe → integracyjne → dokumentacja; szablony discovery/issue/ADR |
| `szablony/commit/` | Szablon commitu dla ludzi (`git commit.template`) i dla Copilota (generowanie opisu commitu) |
| `agent-samples/` | Wzorcowy `AGENTS.md` fikcyjnego projektu PostOp Companion |

Kod Mood Trackera dla studentów i briefy C01–C07 są przekazywane jako archiwa ZIP, poza tym
repozytorium. Wszystkie dane w materiałach są syntetyczne.
